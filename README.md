# Diwali surprise · Day 11 of 100

A Diwali surprise made in one file of plain canvas JavaScript. No libraries.

Open `index.html` in a browser. The page is the whole show:

1. A midnight sky with 1,400 twinkling stars, a glowing moon, floating golden motes and diyas with flickering flames.
2. A name box and a golden button. Type a name and press "Open Your Surprise".
3. A cinematic flash, then fireworks in gold, pink, purple and blue, with floating hearts.
4. "Happy Diwali, <name>!" and then "Happy Diwali, My Life's Light".

The code in `surprise.js` is what runs. The reel shows it typed in an editor and then running at real speed.

Files:
- `index.html`: the page, which loads the script
- `surprise.js`: the whole animation (about 180 lines)
- `preview.jpg`: the finished frame
